## 1. 完整一集输出

依次输出：

1. 项目或本集诊断：核心判断、人物/关系、六张结构图、按职业分类的主创方法矩阵、原创导演圣经、角色表演圣经、母题、本集任务。新项目完整输出一次，后续只报告变化。
2. 资产与缺口：角色、场景主/反向视角、道具、群像、音色和缺失素材。
3. 全集分段总表：覆盖全部来源节点与原台词，并标出前1.5秒钩子、核心冲击镜头、对比轴、视觉变化和结尾钩子。
4. 全部分段完整提示词：每段独立、连续、完整。
5. 全集连续性交接表：人物、朝向、视线、手部、道具、动作、情绪、声音、光向、群像和下一段首动作。

## 2. 基础资产映射

先在项目资产账本中为素材建立跨集稳定的内部语义ID：

```text
CHAR_LUZHENG = 陆峥角色参考
SCENE_COCKPIT_MAIN = 驾驶舱主视角
PROP_LOGBOOK = 飞行日志
VOICE_LUZHENG = 陆峥参考音色
```

内部ID负责身份和跨段连续性，不等同于上传序号。每个独立视频段根据该段实际使用素材，从上到下重新生成执行映射：图片从`@[图片1]`连续编号，音频从`@[音频1]`连续编号；下一段再次从1开始，不沿用上一段号码。

```text
陆峥 = @[图片1]
驾驶舱主视角 = @[图片2]
飞行日志 = @[图片3]
陆峥参考音色 = @[音频1]
```

- 只列本段实际使用素材，编号不得跳号、重复或预留。
- 同一语义ID在不同段可以对应不同的本地`@[图片N]`序号，但身份不能改变。
- 映射顺序按本段第一次实际使用：主要场景、核心人物、实际入画配角、关键道具、群像/色卡；用户明确指定上传顺序时服从用户。
- 用户提供且需要锁定外观/跨段连续性的关键道具单列；一次性临时小道具默认文字描述即可。反向场景图视为独立方向参考。
- 不在映射行加外貌、服装或场景美术；正文也不重建参考图视觉。
- 无参考素材时明确写“未提供参考素材；人物与场景仅使用剧本中的功能标签”，不得补造资产编号、外貌、服装或场景美术。

## 3. 单段八模块模板

严格使用以下八个模块和顺序：

```text
# 第X段｜来源场次｜段落名称｜X秒

[声画硬锁]
无字幕。无背景音乐。
写本段允许的人物台词、环境声、动作声、呼吸和道具声。
原台词逐字保留；音效使用<>，台词使用{}。

[参考图 / 音频对应表]
只列本段实际使用的场景、人物、群像、用户提供且需要锁定的关键道具和音色，每项一行；图片从@[图片1]、音频从@[音频1]分别连续编号。参考表只定义编号，镜头正文仍需在实际可见/可听时调用对应素材。
无参考素材时写“未提供参考素材；人物与场景仅使用剧本中的功能标签”。

[本段任务]
目标模型档与时长范围；承接状态；唯一核心事件；冲突；情绪起点→终点；权力起点→终点；观众视点与信息控制；前1.5秒钩子；核心冲击镜头；至少两种对比轴；2.0按2–3秒、2.5按2–4秒规划有效视觉变化；2.5长段列出2–4个连续微节拍；关键台词视觉落点；对白字符数、语速与基础时长；气口、动作、反应和可重叠时间；结束钩子。

[人物状态、站位、轴线与群像]
主要人物的表层情绪、底层目标、策略和退出状态；初始左右、前后、高低；身体朝向与眼神目标；主要路径、接触点和落点；关系轴与摄影机允许区域；群像近中远层；关键道具基础状态（持有人、左右手、位置、开/关等必要信息）；本段结束站位。未改变信息不在逐镜重复。

[风格、光影与氛围]
写综合后的原创摄影语法，不写导演姓名。先继承项目级不变量：媒介、镜头体系、影像响应、默认构图/运动原则和调色边界；再写本段变量：实际主光来源、方向和摄影机所在侧，人物/背景曝光与冷暖、主辅警示色、景深层级、空气、风、尘、烟、天气和物理质感。若项目级表述与本场实际光源冲突，以场景物理事实修正项目级抽象语句，不允许两个互斥光线指令同时存在。

[镜头时间轴]
每镜一个完整段落，按0.1秒规划精度和镜头行契约书写；稳定状态不在每镜重复。

[声音与剪辑]
只写全段持续room tone、环境层、远近关系、J/L-cut、声音桥、抽空/恢复、对白跨镜、整体切点和结尾声音。单次声音不重复。

[连续性底线]
只保留本段必要的左右、高低、前后、道具/持有手、动作次数、接触点、落点、群像边界、轴线、光向和跨段承接，以及针对实际失败的简短禁止项。不得增加风险或执行策略模块。
```

## 4. 镜头行契约

每个镜头写成一个段落：

```text
镜头N｜起止时间（0.1秒精度）｜功能节点/强度（交代、蓄力、IMPACT或余震）｜焦段、f/数值、景别、机位、构图、主要运镜与最多一种增强语法；摄影机起点→触发→路径/距离/角度/速度→落点与最终焦点；只写相对上一镜变化的站位和视线；动作起点→过程→接触点→落点与有因余波；刺激→眼神路线→2–5项当前景别可见的表情/身体泄露→控制或释放；台词前气口；角色：{原台词}；关键词、音量、速度依据、尾音；台词期间视觉推进；台词后听者/群像余震；本镜特殊声音与剪辑点；本镜结束状态。
```

不含台词的镜头删除台词字段，不写占位符。每镜时码连续、总和等于本段时长。

每镜只写实际入画人物与可见道具。未入画人物不得获得屏幕左右或前后位置；画外目标只写“画面左侧画外”“画面右侧画外”或“画外”。当观众必须知道目标身份时，切反打、POV或插入镜让目标入画。

## 5. 信息唯一归属

| 信息 | 唯一模块 |
|---|---|
| 本段执行素材身份 | 参考图/音频对应表 |
| 目标模型、剧情意义与时长 | 本段任务 |
| 初始站位、轴线、总体群像 | 人物状态、站位、轴线与群像 |
| 项目画面规则 | 风格、光影与氛围 |
| 镜头强度、动作、微表情、台词、单次声音 | 镜头时间轴 |
| 持续声音和跨镜剪辑 | 声音与剪辑 |
| 不变连续状态 | 连续性底线 |
| 风险判断 | 仅内部，不输出 |

若重复，保留在唯一负责模块并删除其他位置。

## 6. 快速执行版

仅在用户明确要求简洁、快速、直接复制，或低复杂度单段任务时使用。内部仍完成完整计时、Dialogue Beat Map（适用时）、Reaction Ownership、表演链、blocking、基础参考绑定、关键道具状态、镜头功能和后置空间审查；只压缩最终呈现。

```text
# 第X段｜来源场次｜段落名称｜X秒

[STYLELOCK]
本段完整可独立执行的介质、镜头体系、影像响应、原创构图/运动规则、光影与声音硬锁。全局风格与场景变量不得冲突；不写创作者姓名。

[REFERENCE]
只列本段素材；图片从@[图片1]、音频从@[音频1]分别连续编号。无素材则写固定缺省句。

[SHOT]
只写第一帧：前1.5秒钩子主体、景别、焦段、机位、构图、初始站位/姿态/视线/手位、关键道具基础状态、摄影机与环境初始运动。非首段用完整文字重建承接状态，但必须换一个可剪辑的画面组织。

[BEATS]
按0.1秒规划时间顺序写可读节拍：Seedance 2.0通常3–8个，Seedance 2.5通常5–12个；标明本段唯一IMPACT镜。2.5长段必须把2–4个连续微节拍串成同一个戏剧目标。每个切镜含功能/强度、主体、焦段/景别、机位/构图、一个主要运动和最多一个增强语法、入画人物站位/眼线、动作接触与落点、有因次级余波、表演链、原台词、台词视觉推进、听者/群像余震、单次声音、剪辑点和结束状态。整体至少两种对比轴；2.0原则上每2–3秒、2.5原则上每2–4秒一次有效视觉变化；末尾写持续声场、无字幕、无背景音乐与跨段退出状态。
```

快速版不得使用“同上”“沿用前文”，不得省略原台词、必要听者反应、动作接触、道具交接、段末状态或本段参考映射。复杂群像、动作链、跨场景或整集默认返回八模块完整版。

## 7. 分批交付

内容超长时：先交付完整分段总表；再按连续段号分批；每批标明覆盖段号和剩余段数；下一批从前一批退出状态继续。禁止用“同上”“沿用前文”“后续同理”代替任何八模块。

## 8. 改单段

读取项目圣经、分段总表、前段退出和后段进入。只改用户指定问题；原台词、参考映射、最终落点和未授权设计保持不变。改后重新审查该段与相邻两段连续性。
