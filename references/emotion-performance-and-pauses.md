## 1. 情绪分析

每个主要人物回答：刚发生的事实、表层情绪、不能公开承认的底层心理、本段目标、障碍、失败代价、触发点、开始策略、策略变化和退出状态。

情绪必须由事实触发并改变策略。删除不能改变行为、声音、空间或注意力的空泛情绪词。

## 2. 可表演的目标与策略

不要指导“更悲伤”“更愤怒”。指导试探、拖延、掩饰、迫使、安抚、拒绝、保护、挑衅、求证、占据、退出等可执行动词。

让人物一边做有目的的事一边说话，例如整理道具以恢复控制、擦拭以拖延、挡住出口。动作必须改变关系，不是无意义忙碌。

## 3. 反应链

`刺激可被感知 → 感官登记 → 内部理解 → 不由自主的泄露 → 恢复/掩饰 → 动作或台词 → 听者反应`

除非故意打断或否认，人物不能在尚未处理信息前回答。多人反应加入0.1–0.6秒差异，避免所有人同时转头或震惊。

## 4. 微表情选择

普通镜头只选2–4类，关键情绪特写选4–5类：眼神路线；眉眼与眨眼；嘴唇与下颌；呼吸与喉部；手部；肩膀、脊柱、骨盆和重心。

FACS只用于内部区分眉额、眼睑、面中、嘴唇、下颌与头颈的动作来源；最终写观众可见的变化顺序，不堆AU编号、肌肉名称或毫米数。表演细度必须匹配景别。

写因果而非清单：

```text
听见关键词后，眼睛先停在对方嘴上，呼吸断半拍；手指先收紧又刻意松开，才抬眼回答。
```

## 5. 台词和气口

每句关键台词设计：开口前看向哪里；是否吸气、吞咽、失败起音或停下动作；关键词音量、速度和重音；尾音如何结束；谁先反应。

默认对白使用统一常速规划值。愤怒、命令、权威、悲伤、克制或震惊只改变声量、重音、气口、尾音、停顿和身体节奏，不自动改变字/秒。只有原文或用户明确写出快说、抢白、打断、缓慢、一字一顿等速度证据时才切换快/慢档，并在分段表记录依据。

参考停顿：普通开口前0.15–0.3秒，困难台词前0.3–0.6秒，吞咽/重置0.3–1秒，重要听者反应0.4–1.2秒，决定性台词后0.3–0.8秒。

停顿是人物处理事实，不是机械空白。用room tone、呼吸、衣料或道具声维持空间生命。

## 6. 听者反应

- 说话者台词L-cut进入听者脸；
- 听者先发生眼神或动作变化，再决定是否回答；
- 多人场景安排不同注意目标和延迟；
- 反应必须改变后续动作、策略或权力关系。
- 狠话、身份、证据或反杀台词后，优先保留0.3–1.2秒有效余震，让对手、听者或群像证明爽点成立。

不要让所有镜头停在说话者脸上，也不要在关键词落下后立即切走。

## 7. 表演去重

- 角色表演圣经负责稳定习惯；本段只写习惯如何受压力改变。
- 站位模块写整体目标和策略；具体眼神、微表情、气口只写入发生它的镜头。
- 同一段不反复用握拳、抿嘴、皱眉代表所有情绪。
- 情绪越大越需要清楚的蓄力—释放—余震对比。释放点可以使用更强动作、景别或运镜，但不能所有镜头同时放大表演。
