## 1. 输入边界

- 收到整部或多集剧本：读到结尾后再处理目标集，记录后续揭示对当前集的反向影响。
- 只收到一集：完成本集级分析，未知后续保持未知，不虚构全剧弧光。
- 只收到片段：明确为片段级处理；若用户要求整集分段，索要其余文本。
- 输入为DOCX/PDF：先用对应文件技能完整提取正文；核对场次、对白和结尾，不能只依赖预览页。

## 2. 完整项目诊断

用因果而不是形容词回答：

1. 格式、类型、目标观众、单集长度和生产媒介是什么？
2. 项目属于哪种短剧承诺：身份逆袭、能力反杀、情感打脸、悬疑揭晓、动作闯关、喜剧反转或混合型？观众每隔多长时间应获得一次信息、情绪或视觉回报？
3. 核心命题能通过什么选择或代价被证明？
4. 主角公开目标、隐秘需要、伤口、错误信念、常用策略和道德底线是什么？
5. 主要对抗力来自人物、制度、环境、记忆还是自我？它为什么有效？
6. 哪个世界规则或关系持续制造新事件？
7. 主角不行动、失败或越界分别会失去什么？
8. 故事如何从扰动走向承诺、升级、中点、最低谷、选择、高潮和结果？
9. 观众、主角、对手各自知道什么；何时产生知识差？
10. 哪些伏笔、道具、动作、声音和颜色会被回收？
11. 角色数量、场景、动作、群像、特效、参考素材和AI稳定性有什么现实约束？

## 3. 六张结构图

### 全局情绪曲线

写成“事实—情绪—行为—电影后果”：

`常态裂缝 → 压力累积 → 情绪破口 → 反作用力 → 不可逆选择 → 新状态`

### 关系曲线

记录每个关键节点的距离、信任、债、控制、保护、背叛和权力归属；用具体行为证明变化。

### 本集情绪曲线

标记前1.5秒钩子、首个问题、中段升级、最大情绪重击、高潮选择和结尾悬念。

### 主观视点曲线

逐场确定摄影机是客观观察、人物对齐、优先知情、主观感官还是制度监视；写清何时转移视点以及转移后的新信息。

### 母题变化曲线

每个视觉、道具、动作、色彩或声音母题按`建立→重复→变异→反转→回收`记录，不能只做装饰。

### 爽点与权力曲线

标记每次压制、忍耐、误判、证据、身份揭示、能力证明、反杀、打脸、群体态度变化和余震。每个爽点记录：权力起点、触发事实、核心视觉落点、谁的反应证明翻盘成立、下一次升级空间。前面的爽点不能透支后面的高潮。

## 4. 主创方法矩阵

新项目至少研究10位真正解决本剧问题的创作者，但必须先按职业分类，不把摄影指导、动作指导、美术指导或剪辑师误写成导演。方法池可替换：

| 职业类别 | 研究重点 | 最终转译位置 |
|---|---|---|
| Visual Director / Director | 叙事视点、调度、信息与表演 | 导演圣经、分段意图卡 |
| Cinematographer | 光线、曝光、镜头、机位与摄影机运动 | 摄影语法、光影规则 |
| Action Director | 动作因果、力量、路线、接触与群体节奏 | 动作链、机位安全与剪辑 |
| Production Designer | 空间、材质、色彩、道具和场景叙事 | 场景家族、视觉母题 |
| Editor / Sound Designer | 时间、切点、声桥、主观声与信息揭示 | 声音剪辑语法 |

内部可以跨职业综合方法，但记录时必须保留真实职业；最终生成提示词只输出转译后的可执行规则，不写“visual direction by 某摄影指导”一类错误标签。

| 创作者 | 可研究的普遍方法 | 适用问题 | 慎用倾向 |
|---|---|---|---|
| Steven Spielberg | 反应先行、纵深调度、视线引导揭示 | 奇观、发现、保护 | 过度煽情 |
| David Fincher | 信息精度、受控机位、微行为 | 制度、调查、心理控制 | 全剧过冷 |
| Denis Villeneuve | 负空间、尺度、耐心揭示、低频压力 | 巨构、世界异常 | 日常戏过慢 |
| Bong Joon-ho | 空间阶级、调性转折、群体调度 | 甜美表面下的制度 | 黑色幽默抢情感 |
| Park Chan-wook | 几何权力、物件和眼线、图形转场 | 道具、对峙、欲望 | 华丽压过因果 |
| Zhang Yimou | 色彩等级、仪式群像、重复动作 | 集体秩序、庆典 | 视觉表演空心化 |
| Alfred Hitchcock | POV—对象—反应、观众知识控制 | 悬疑、异常、危险预期 | 过度解释悬念 |
| Akira Kurosawa | 多平面动作、清楚运动矢量、群体层次 | 动作、战斗、群众 | 规模超出生产能力 |
| Alfonso Cuarón | 连续空间、前中后景、身体化跟随 | 穿行、救援、现场感 | 无意义长镜头 |
| Ang Lee | 礼仪压抑、气口、距离和克制 | 亲密关系、隐忍 | 节奏过度静止 |
| Céline Sciamma | 凝视、沉默、相互观察 | 私密悲伤、女性/儿童视点 | 表演成人化 |
| Jordan Peele | 宽画面社会不安、日常异化、声画触发 | 集体秩序、笑容威胁 | 滥用惊吓 |
| Hirokazu Kore-eda | 日常观察、离屏压力、反应时间 | 家庭、儿童、生活质感 | 缺少类型推进 |
| Edward Yang | 建筑框架、社会系统、同步行动 | 城市、群像、关系距离 | 人物过小过远 |
| Hayao Miyazaki | 可触摸的奇观、身体与世界互动 | 动画世界、探索、飞行 | 复刻具体设计 |
| Satoshi Kon | 主观转场、图形匹配、记忆接缝 | 回忆、异常、心理断层 | 时间线难懂 |
| Brad Bird | 动作轮廓、准备—爆发—落点 | 动画动作、救援、喜剧 | 只追速度 |

对每位创作者填写：真实职业、相关问题、一般原则、信息控制、调度、镜头/运动、光色、表演、声音/剪辑、最佳场景和禁止引入项。不要对其全部作品武断指定固定焦段。

## 5. 原创方法综合

完成矩阵后：

1. 选择2–4项项目级主原则；
2. 选择3–5项场景级辅助原则；
3. 将其余手法限制在稀有节点；
4. 解决互相矛盾的方法，例如静态观察与运动摄影、写实与奇观；
5. 翻译为项目自己的镜头、站位、光线、表演、声音和剪辑规则；
6. 最终提示词只写翻译后的规则，不写导演姓名或“模仿”。

每个分段只调用：一个主原则、一个辅助原则、至多一种限制技法。

## 6. 项目导演圣经

首次处理新项目时输出：

```text
核心基调：情绪温度、现实度、类型承诺和道德视点。
叙事节奏：问题密度、反应时间、沉默阈值、结尾钩子。
短剧回报：前1.5秒钩子、每段核心冲击点、视觉变化阈值、爽点升级和余震原则。
观众视点：默认跟随者、知识差和主观化触发条件。
摄影语法：默认焦段家族、机位高度、静动比例、特写阈值、运动触发。
视觉对比：远近、快慢、动静、高低、稳定/失控、边缘/中心如何服务权力变化。
调度语法：权力、亲密、危险、保护和反转如何通过空间表达。
表演语法：眼神、呼吸、动作幅度、声音压力、情绪释放上限。
光色质感：来源光、对比、色温、饱和度、皮肤和环境曝光。
群像语法：近中远层次、同步与错拍、核心表演区。
声音剪辑：空间声、母题、J/L-cut、声音抽空、切镜密度。
禁止语法：不得滥用的镜头、光效、剪辑和表演。
```

## 7. 角色表演圣经

每个主要角色建立固定档案：

```text
公开身份与隐秘自我：
长期目标、伤口、误区和底线：
常态身体节奏与重心：
习惯性眼神路线：
紧张时首先泄露的位置：
掩饰或撒谎时的动作：
悲伤、愤怒、恐惧、保护状态的差异：
行动前准备动作：
声音音高、速度、气口和尾音：
面对不同人物时的变化：
情绪外放上限：
```

后续镜头从档案调用，不给同一角色反复发明同一种握拳、瞪眼或抿嘴。

## 8. 场景家族与母题

至少区分奇观发现、温柔异常、制度压迫、私密悲伤、喜剧互动、动作救援、群体审判、真相空间、记忆和悬念。每类预设：视点、镜头家族、运镜频率、表演尺度、群像、光色、声音和剪辑。

母题表记录：名称、首次含义、重复方式、何时变异、最终回收、对应声音和色彩。不得用新母题挤掉原剧本已经建立的母题。
