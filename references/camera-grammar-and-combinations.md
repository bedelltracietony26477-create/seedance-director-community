## 1. 镜头功能节点

每镜只设一个主功能：

- `WORLD`：世界、路线、规模；
- `RELATION`：距离、权力、联盟；
- `ACTION`：可读的身体选择与接触；
- `EMOTION`：理解、决定、压抑或释放；
- `DETAIL`：道具、手、证据、物理信息；
- `SYSTEM`：制度、规则、监视、群体秩序；
- `BRIDGE`：空间、时间、动作或声音承接；
- `HOOK`：未解决的信息、声音、眼神或动作。
- `IMPACT`：本段唯一核心视觉爆点、权力翻转或动作落点。

目的镜头必须增加新信息或新感受，不能只换景别重复上一镜。

## 2. 短剧镜头强度

每段组合四类强度：

- 交代镜：空间、人物和关系可读；
- 蓄力镜：压力、动作准备、证据逼近或情绪控制；
- 冲击镜：本段唯一`IMPACT`，让爽点、狠话、身份、动作或反应达到最大视觉清晰度；
- 余震镜：对手、听者、群像、环境或道具结果证明冲击成立并留下钩子。

Seedance 2.0的13–15秒通常5–8镜；Seedance 2.5长段按容量扩展：16–20秒常用5–9镜，21–25秒常用6–10镜，26–30秒常用7–12镜。2.0原则上每2–3秒、2.5原则上每2–4秒发生一次有效视觉变化；变化可以是景别、主体、机位高度、运动、焦点、遮挡、声音或权力构图，不等于必须切镜。连续三镜不得维持相同主体、相近景别、同一高度和同一运动状态，除非刻意制造压迫或情绪Hold。

## 3. 焦段与景别

焦段是视觉语义，不是保证的物理元数据：

| 范围 | 主要功能 | 常用景别 |
|---|---|---|
| 14–21mm | 尺度、路线、高低、超广角视差 | EWS/WS/FS |
| 24–28mm | 动作关系、多人站位、身体路径 | WS/FS/MLS |
| 35–45mm | 现实关系、双人对话、身体与空间 | MLS/MS/Two-shot |
| 50–65mm | 台词、判断、心理靠近 | MCU/CU/OTS |
| 75–100mm | 关键反应、微表情、压迫 | CU/BCU |
| 100mm Macro | 手、眼泪、道具、接触点 | ECU/Insert |
| 135–200mm | 观察、孤立、人群压缩、监视 | 远距MS/CU |

- 复杂动作前先用WS/FS或空间镜头建立关系。
- 关键保护、离开、阻挡应能看见脚步或身体落点。
- 特写只用于观众获得新的心理访问权，不为每句台词自动切CU。
- 超广角边缘不放承担表情的脸；微距后必须接人物反应。

## 4. 机位、构图和运动库

至少掌握并按功能调用以下语法：

### 视点与机位

平视、高机位、低机位、顶视、贴地、POV、OTS、观察者、制度监视、荷兰角。

### 构图

中心、对称、负空间、框中框、前景遮挡、前中后景、多人物三角、高低关系、引导线、分焦构图、长焦层叠。

### 基础运动

静态锁定、慢推、轨道推进、后拉、横移揭示、跟拍、Pan、Tilt、Steadicam、呼吸式手持。

### 复杂运动

30–60度半弧绕拍、受控环绕、Crane/Jib升降、Technocrane复合运动、Whip Pan、Slow Zoom、Crash Zoom、Dolly Zoom、Probe Macro、超广角视差运动。

### 焦点与剪辑连接

Rack Focus、动作匹配、眼线匹配、图形匹配、声音J-cut、L-cut、声音桥、硬切、主观声音切换。

术语必须区分：

- `Rack Focus / Focus Pull`：焦点拉移，只改变对焦平面，不改变焦距与画面视角；写清起始焦点、触发词/动作与最终焦点。
- `Zoom`：镜头改变焦距，改变视角和主体在画面中的比例；不是焦点拉移。
- `Dolly`：摄影机在空间中前后移动，产生透视变化；不是变焦。
- `Dolly Zoom`：摄影机移动与反向变焦同步，维持主体大小并改变背景透视；仅在明确心理失重节点使用。

禁止把`Rack Focus`翻译成“变焦拉焦”，也禁止用`Zoom`代替对焦变化。

## 5. 单镜组合规则

使用：

`功能 + 视点 + 焦段/景别 + 机位/构图 + 一个主要运动 + 最多一个增强语法 + 焦点/剪辑连接`

复杂运镜必须写：摄影机起点→触发→方向→路径/角度/距离→速度→落点→最终焦点→叙事情绪作用。

不要在一镜堆POV、荷兰角、360环绕、Crash Zoom、Dolly Zoom、Whip Pan和大幅手持。通常只保留一个主要移动、一个增强和一个焦点变化。

## 6. 情绪组合配方

| 情绪目的 | 可执行组合 |
|---|---|
| 孤立与群体压力 | 135mm长焦压缩＋前景遮挡＋极慢Push-in |
| 难以说出口的悲伤 | 85mm静态CU＋5–8度荷兰角＋台词后Hold |
| 被一句话击中 | 人物对齐POV＋Rack Focus到目标＋135mm反应 |
| 犹豫后决定 | 100mm手部Insert＋眼神CU＋低机位Dolly Push-in |
| 公开保护 | 35mm低机位三角构图＋25–45度半弧绕 |
| 权力失衡 | 高低构图＋前景边界＋慢横移揭示 |
| 异常闯入 | 声音J-cut＋眼神登记＋Whip Pan到清楚落点 |
| 心理失重 | 主体稳定＋克制Dolly Zoom＋声音收窄 |
| 强忍崩溃 | 85mm静态压脸＋手部Insert＋L-cut听者反应 |
| 群体秩序裂开 | 对称大景＋不同步反应＋中心空隙被动作切开 |

这些是起点，不是固定套版。根据空间、视点和表演重新组合。

## 7. 动作与复杂运镜

动作先设计物理过程，再决定摄影机：

`预备 → 发力 → 运动 → 接触 → 惯性/反作用 → 落地姿态 → 衣料/头发/道具余波`

镜头负责让动作因果可读：

- 广角展示空间、路线和尺度锚点；
- 中近景展示接触、手部和重心；
- 反应镜头展示动作改变了谁；
- 声音强化发力、接触和余波，不靠背景音乐；
- 复杂运动不能遮蔽脸、接触点或落点。
- 每个动作段至少有一种冲击表达：复杂运动、稳定大全景、尺度参照、动静突变、动作匹配切或声音撞点均可；不强制复杂运镜。

若一个镜头反复失败，内部决策优先拆为准备镜头与结果镜头；最终只输出拆后的正常镜头，不输出风险分析。
