## 1. 模型档与本集分析

先读取`model-duration-profiles.md`并锁定目标模型档。Seedance 2.0使用8–15秒；Seedance 2.5使用16–30秒，用户明确要求15–30秒或戏剧边界恰好完整时允许15秒边界段。未指定时默认Seedance 2.0。

先为每场戏建立：场景所有者、即时目标、阻力、策略、策略变化、信息变化、权力变化、进入状态、离开状态和下一场钩子。

再确定本集：开场钩子、主要问题、升级节点、中段转折、高潮、不可逆选择、结尾悬念，以及人物/道具/场景的连续状态。

在开始分段前，为原剧本中的场次、每句台词、关键动作、环境变化、信息揭示、心理转折和必要过渡建立稳定且唯一的来源编号，例如`S01`、`D001`、`A001`、`E001`、`P001`。编号只用于内部覆盖账本、分段总表和审计，不得写进角色实际台词。无法直接视觉化的心理节点必须通过人物行为、声音、道具或环境结果等价覆盖。

## 2. 对白计时

统计中文字符和有效数字，排除标点与说话者标签。先判定原文是否给出明确速度证据，再选语速档；冲突、命令、悲伤、权威、震惊等情绪标签本身不构成换档证据。

| 速度档 | 触发条件 | 规划值 |
|---|---|---:|
| 常速（默认） | 原文未明确速度；包括普通交流、冲突、命令、权威、悲伤、震惊 | 4.2字/秒 |
| 快档 | 原文或用户明确“快速、急促、连珠炮、抢白、打断、赶时间、一口气说完” | 4.6字/秒 |
| 慢档 | 原文或用户明确“缓慢、迟疑、一字一顿、拖长音、说不出口” | 3.6字/秒 |

`基础时长 = 有效字符数 ÷ 语速`

同一句台词和同一速度证据必须复用首次规划值，不因后来将人物标注为愤怒、冷静或痛苦而重算。情绪通过开口前处理、标点、吞咽、失败起音、重音、声量、尾音和听者反应体现。若需要偏离规划值，必须记录原文速度证据；不得用“短剧节奏快”作为理由。

基础时长之外选择性增加：

| 项目 | 常用范围 |
|---|---:|
| `、` | 0.10–0.20秒 |
| `，` | 0.15–0.30秒 |
| `；`、`：` | 0.25–0.45秒 |
| `。`、`？`、`！` | 0.25–0.60秒 |
| `……` | 0.60–1.20秒 |
| 普通开口前气口 | 0.15–0.30秒 |
| 困难台词前 | 0.30–0.60秒 |
| 吞咽、失败起音、情绪重置 | 0.30–1.00秒 |
| 重要台词后的听者反应 | 0.40–1.20秒 |
| 决定性台词后的悬停 | 0.30–0.80秒 |

不要把所有最大值相加。停顿必须揭示意图。

使用`scripts/dialogue_timing.py`得到可复核的稳定规划值和表演区间。`neutral`、`authoritative`、`restrained`、`shock`共享常速对白，差异只体现在气口、标点权重和反应；`urgent`仅供原文明确快说、抢白或打断时使用。

镜头与声音时间码按0.1秒记录，用于规划连续性、切点和关键同步；它不是对生成模型的100毫秒执行保证。不要把每0.1秒写成独立动作段，也不要重复未变化状态。

## 3. 表演和动作计时

单独估算不能和说话同时完成的内容：

- 刺激被感知与理解：0.2–0.8秒；
- 眼神转移或一次微小反应：0.2–0.5秒；
- 站起、蹲下、退半步、转身：0.5–1.5秒；
- 接近、递取、阻挡等动作：按起点—路径—接触—落点估算；
- 跳跃、碰撞、落地：必须留预备与物理余波；
- 关键听者反应：0.4–1.2秒；
- 情绪悬停：0.3–0.8秒。

允许自然重叠，例如走路时说话；不能把吞咽、失语、剧烈转身和清晰长台词强行同时执行。记录可重叠秒数，避免重复相加。

## 4. 分段算法

### 第一次切分：戏剧边界

在以下节点候选切分：新事实、策略改变、权力改变、主要动作开始/完成、关键台词及反应、视点变化、声音/眼神/未完成动作钩子。

每个候选段同时标出：前1.5秒钩子、一个核心冲击镜头、至少两种对比轴、2–3秒视觉变化节点和结尾余震。若没有冲击点，检查该段是否应与相邻段合并或重新选择边界。

### 第二次合并：向当前模型的有效容量靠近

Seedance 2.0可在戏剧自然时向13–15秒靠近；Seedance 2.5可在同一主要目标持续成立时向16–30秒合并。相邻候选段只有在下列条件同时成立时合并：仍只有一个主要戏剧目标；空间、视点和情绪因果连续；台词、气口、动作、反应自然落在当前模型上限内；合并后内部存在2–4个可辨微节拍；不需要无意义填充；复杂动作和核心对白不互相抢容量。

### 第三次拆解：超时与过载

按顺序处理：在戏剧性分句或听者反应处拆段；让台词L-cut跨到听者镜头；把复杂动作拆为准备/结果；新增下一段；只有用户授权时改写台词。Seedance 2.0超过15秒必须拆；Seedance 2.5超过30秒必须拆。

## 5. 分段质量

### Seedance 2.0

- 8–15秒为标准范围；大多数自然段可落在13–15秒。
- 8–12秒适合短转折、短动作、短对白。
- 低于8秒只用于无法合理合并的桥接、钩子或极短转场；必须注明原因，且不能成为多数。
- 8–10秒：3–5镜；10–12秒：4–7镜；13–15秒：优先5–8镜。

### Seedance 2.5

- 16–30秒为标准范围；用户明确要求15–30秒或戏剧边界恰好完整时允许15秒边界段。
- 16–20秒：常用5–9镜；21–25秒：常用6–10镜；26–30秒：常用7–12镜。
- 长段必须维持一个主要戏剧目标，并具备2–4个连续微节拍；不能通过重复反应、空镜或无意义走路拉长。
- 原则上每2–4秒发生一次有效视觉变化，并在中段至少出现一次策略、距离、主体、动作或权力关系上的推进。

### 两档共用

- 情绪高点可以用更少镜头和更长Hold；动作段可以增加镜头，但每镜必须可读。
- 一个镜头只承载一个主要动作；动作超过三个清晰阶段时优先拆镜。
- 不按固定秒数切断原台词、呼吸或动作接触。
- 短剧节奏快不等于人物快念；通过景别、主体、动作、焦点、声音和权力构图变化提高密度。
- 超过3秒的长对白必须有内部视觉推进，但允许关键表演持续停留在说话人脸上。

## 6. 分段总表

写任何完整提示词前，先输出覆盖全部目标集的总表：

| 字段 | 内容 |
|---|---|
| 段号 | 连续编号 |
| 来源场次 | 原剧本场次 |
| 目标模型档 | Seedance 2.0 / Seedance 2.5 |
| 建议时长 | 2.0：8–15秒；2.5：16–30秒，15秒边界例外注明原因 |
| 核心事件 | 一个主要变化 |
| 前1.5秒钩子 | 人物/冲突/动作/道具/声音 |
| 核心冲击镜头 | 本段唯一主爆点及预计时间 |
| 对比轴 | 至少两种视觉或声音对比 |
| 视觉变化节点 | 原则上每2–3秒一次有效变化 |
| 情绪起点→终点 | 可见转化 |
| 原台词 | 逐字、按原序 |
| 对白基础时长 | 字数、语速区间 |
| 气口与反应 | 选定秒数 |
| 动作与可重叠时间 | 非语言占用 |
| 核心人物 | 本段视点与反应对象 |
| 群像 | 无/近中远层级 |
| 进入状态 | 承接上一段 |
| 退出状态 | 交给下一段 |
| 结尾钩子 | 狠话/动作落点/身份或证据/反应/声音/未完成状态 |

检查总表是否覆盖所有来源节点和原台词；同一节点不得重复分配或遗漏。使用`scripts/segment_timing_audit.py`审查容量、覆盖、钩子、冲击点、对比轴和视觉静止区间。
