## 1. 短剧目标

爽文短剧优先满足：观众一眼看懂谁压谁、发生了什么变化、哪句话是狠话、哪个反应证明翻盘成立。电影技术用于提高信息清晰度、情绪代入和视觉刺激，不用慢节奏、长空镜或含混构图证明“高级”。

短剧的冲击不等于每镜都快速运动。有效结构是：

直接进入 → 压力建立 → 视觉蓄力 → 核心爆点 → 对手/群像余震 → 结尾钩子

爆点前必须有相对低强度状态，爆点后必须给结果或反应；只有爆发没有蓄力和余震，观众不会感到翻盘。

## 2. 爽点与权力曲线

处理每集前标出：

- 身份爽点：隐藏身份、资格、实力、背景被确认；
- 信息爽点：证据、真相、秘密、误判被揭开；
- 权力爽点：被压制者取得空间、话语、道具或行动控制；
- 能力爽点：别人做不到，主角以清楚动作完成；
- 情绪爽点：忍耐结束、边界建立、关系决裂或被保护；
- 群体爽点：旁观者、敌方阵营或权威人物的态度发生变化；
- 动作爽点：预备、爆发、接触、位移、落点和余波清楚成立。

为每个爽点记录：谁此前占优、观众期待什么、什么事实或动作触发、权力如何改变、谁的反应证明改变成立、下一段还剩什么未解决。不得仅靠主角说“我赢了”完成翻盘。

每段内部填写：

    2–3秒视觉变化节点：

    对手/听者余震：
    结尾钩子：

一个片段只设一个核心冲击镜头。其他镜头可以强，但不得与核心爆点竞争。

## 4. 前1.5秒钩子

优先选择：

- 动作已经开始但尚未完成；
- 人物带着强烈状态直接开口；
- 占据画面的关键证据、伤痕、武器、身份物或手部动作；
- 反派最嚣张的一句或最具压迫性的站位；
- 异常声音J-cut触发人物视线；
- 上段未完成动作的动接动承接；
- 主角被压在画面边缘、低位或遮挡后的立即反应；
- 群像突然分开、停止、回头或露出通道。

环境建立只有在尺度、危险、阶级或路线本身就是冲突时才作为开场；否则把环境信息嵌进人物动作镜头。

## 5. 视觉变化与强度曲线

每2–3秒安排一次有效变化，但不机械按秒切镜。有效变化包括：

- 主体转移；
- 景别跨级变化，如WS直接切CU；
- 机位高度或权力构图变化；
- 稳定转运动、运动转锁定；
- 长焦压缩转广角释放；
- 前景遮挡被人物切开；
- 焦点从道具转向人物眼睛；
- 人物从边缘进入中心；
- 群像从持续状态形成错拍反应波；
- 正常声场收窄为呼吸、衣料或关键道具声；
- 光源、门窗、烟尘、天气或空间边界发生有因变化。

推荐强度曲线不是固定剪辑模板：

- 0.0–1.5秒：直接钩子；
- 1.5–4.0秒：关系或压力可读；
- 4.0–8.0秒：策略、证据或动作升级；
- 8.0–12.0秒：核心冲击镜头；
- 12.0–15.0秒：听者余震与下一段钩子。

若核心爆点发生更早，后半段必须展示后果、二次反转或新威胁，不能重复庆祝同一个爽点。

## 6. 对比轴

每段至少选择两种，并让它们服务同一权力变化：

| 对比轴 | 可执行方式 |
|---|---|
| 远→近 | 先建立人数/空间，再切关键脸、眼神或证据 |
| 近→远 | 私人决定落下后揭示群体或环境后果 |
| 高→低 | 受压者由高机位转为平视/低机位 |
| 边缘→中心 | 翻盘者通过走位、构图或前景切入占据中心 |
| 静→动 | 身体或摄影机在触发点突然启动 |
| 动→静 | 动作落点后锁镜，让结果和表情承担冲击 |
| 慢→快 | 蓄力镜后用短促动作/剪辑释放 |
| 快→慢 | 接触瞬间后延长结果或反应，不滥用慢动作 |
| 长焦→广角 | 压缩受困转为空间/动作释放 |
| 喧闹→收窄 | 爽点前建立声场，关键词处只留近身声音 |
| 被遮→显露 | 前景、群像、门或道具让开后揭示主角/证据 |
| 被压→反压 | 站位、距离、视线高度和画面占比共同翻转 |

## 7. 关键台词视觉落点

一句狠话、身份台词或真相台词必须确定：

1. 开口前触发；
2. 关键词对应的主体；
3. 台词期间的视觉推进；
4. 关键词落下时的镜头/动作/声音撞点；
5. 台词后的听者或群像余震。

长对白超过约3秒时，可采用：

- 台词L-cut到听者表情；
- 切关键道具、证据、脚步、手部或空间后果；
- 在同一镜内由中景推进近景；
- 说话人完成一次改变关系的走位；
- 焦点从说话人转到被点名者；
- 保持说话人特写，但让刺激、控制和释放在脸上连续发生。

禁止机械插入无叙事作用的空镜，也禁止每句台词都用相同正反打。

## 8. 场景类型配方

### 身份揭晓/打脸

先保留误判者优势→证据或身份物进入→误判者动作/笑容停住→主角权力构图建立→狠话落点→群像错拍反应。

### 对峙/命令

用前景边界、人物距离、高低和出口控制建立压力；命令台词不自动加快语速。真正的爽点来自谁执行、谁拒绝、谁跨过边界。

### 情绪决裂

先让人物试图维持关系，再让身体泄露失败；核心台词尽量落在清楚脸部和眼神上，切镜减少但景别/焦点/声音可以变化。

### 动作反杀

先用空间镜建立路线和尺度→准备/发力→接触点→反作用和位移→稳定落点→对手或群像余震。复杂运镜不得遮蔽接触和落地。

### 奇观/能力展示

先给人物或建筑作为尺度参照，再展示现象；奇观改变光、空气、衣料、尘雾、声音和旁观者，不是只加发光特效。

### 喜剧反转

维持认真状态完成铺垫，笑点落在信息差、动作结果或反应时差；不靠所有角色一起夸张表演。

## 9. 冲击与可执行性的边界

- 不为“镜头丰富”堆叠多个复杂运动；
- 不用Crash Zoom、Whip Pan或Dolly Zoom替代剧情变化；
- 不把所有镜头都做成特写，必须保留关系和尺度；
- 不让群像、烟尘、特效遮挡关键脸、接触点或落点；
- 不让每个主体持续乱动；有状态比有动作更重要；
- 不用毫米级肌肉位移或逐帧文本制造伪控制；
- 不为了1.5秒钩子破坏上一段动作连续性；
- 不为了每2–3秒变化打断关键台词、呼吸、接触或情绪Hold。
