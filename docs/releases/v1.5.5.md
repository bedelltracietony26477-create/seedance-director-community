## 本版是什么？

v1.5.5 是面向 AI 短剧与连续剧情制作的轻量导演工作流。你提供完整剧本、参考素材及目标模型，工作流依次组织戏剧节拍、人物表演、对白编舞、空间调度、摄影、声音与基础跨段交接，输出分段视频提示词。

交付形式为 Skill 指令、导演参考文档、示例与 Python 标准库审计工具。视频生成在用户选择的平台完成，本项目不内置视频生成服务。

它适合希望保留旧流程的用户、已有项目复现，以及研究社区版本演进的创作者。新项目默认建议使用 [v1.6.0 稳定版](https://github.com/bedelltracietony26477-create/seedance-director-community/releases/tag/v1.6.0)；需要尝试结构化状态账本时，可选择 [v2.0.0-beta.1 预览版](https://github.com/bedelltracietony26477-create/seedance-director-community/releases/tag/v2.0.0-beta.1)。

## v1.5.5 包含哪些导演能力？

| 能力 | 本版工作方式 |
|---|---|
| Exact Dialogue Lock｜原台词硬锁 | 按原人物、原字、原顺序保留台词；容量不足时拆段，不靠删词塞进时长 |
| Dialogue Beat Map Lite｜轻量对白编舞 | 按称呼、事实、攻击、证据、转折、结论等自然语义安排画面推进 |
| Reaction Ownership｜反应所有权 | 判断一句话真正改变了谁，将关键反应画面交给承担变化的人 |
| Failed Action｜未完成动作 | 写清意图、启动、外界抢先、停在半程与可见后果 |
| 身体化表演 | 将情绪落实到呼吸、手、喉部、重心、道具或未完成动作 |
| Blocking / Eyeline / Axis | 先排站位、身体朝向、眼线、行动路径和 180° 轴线，再选机位 |
| 动作过程与电影摄影 | 描述发力、路径、接触、反作用与落点；主要运镜保持清楚 |
| 短剧视觉冲击 | 前1.5秒钩子、核心冲击、对比轴、视觉变化和收尾钩子 |
| 轻量参考绑定 | 每段重新建立人物、场景方向、关键道具与声音的本地编号，并在实际调用镜头中绑定 |
| 基础跨段连续性 | 记录人物、朝向、视线、左右手、关键道具与进入/退出状态 |

同一句现实对白可跨镜，声音事件保持连续；默认对白使用 `{}`，音效使用 `<>`，无字幕、无背景音乐。人物仅对自己已经获得的信息做反应。

## 工作顺序与交付

1. 读取指定范围，建立原文覆盖记录。
2. 分析情绪、人物关系、信息、视点、母题和权力变化。
3. 核算对白、气口、动作、反应及可重叠时间，先产出完整分段总表。
4. 排空间与表演，建立本段参考映射，再安排镜头、发声与切点。
5. 检查原文覆盖、时长、参考绑定、物理动作和基础连续性。

整集任务依次交付项目/本集诊断、资产与缺口、全集分段总表、全部分段提示词及连续性交接表。每段应可独立复制执行，不用“同上”代替必要状态。

默认完整版使用八模块：

| 模块 | 内容 |
|---|---|
| `[声画硬锁]` | 场景、声画与原台词规则 |
| `[参考图 / 音频对应表]` | 本段人物、场景、关键道具与声音映射 |
| `[本段任务]` | 戏剧变化、情绪、冲击、对比、时长与钩子 |
| `[人物状态、站位、轴线与群像]` | 进入状态、空间与行动路径 |
| `[风格、光影与氛围]` | 摄影语法、实际光源与画面质感 |
| `[镜头时间轴]` | 逐镜动作、表演、原台词、声音与切点 |
| `[声音与剪辑]` | 持续声场、对白跨镜与声音桥 |
| `[连续性底线]` | 道具、手位、动作落点与跨段承接 |

明确要求简洁时使用 `[STYLELOCK]`、`[REFERENCE]`、`[SHOT]`、`[BEATS]` 四模块快速版。模板和命令应使用 [v1.5.5 对应文档](https://github.com/bedelltracietony26477-create/seedance-director-community/blob/v1.5.5/references/final-output-contract.md)。

## 时长配置

| 本版工作档 | 标准分段 | 说明 |
|---|---|---|
| Seedance 2.0 档 | 8–15秒 | 未指定模型时的默认档；超出上限继续拆段 |
| Seedance 2.5 档 | 16–30秒 | 明确要求或戏剧边界完整时可用15秒边界段；长段内部保持一个主要目标与2–4个连续微节拍 |

这些是历史版本的时长工作档；执行时按目标平台当前支持的上限分段。0.1秒时间码用于动作、发声与剪辑同步。

v1.5.5 的节奏原则是约每2–3秒出现有效视觉变化，情绪高点可有动机地延长静止镜头；不要将后续 v1.6 的“默认单镜不超过4秒”规则视为旧版已有约束。

## 安装与启动

下载本页实际附件：

**`Seedance_Director_Community_v1.5.5.zip`**

解压后找到包含 `SKILL.md` 的技能目录，按所用平台的 Agent Skills 导入说明安装。历史安装标识是 **`seedance-director-community`**，不是后续版本的 `chuangmeng-director`。

```text
使用 $seedance-director-community 处理以下完整剧本。
目标模型：[填写实际模型与当前平台上限]
保留全部原台词及顺序。
先梳理剧情、表演、空间、对白编舞和完整分段总表，
再输出全部分段的八模块提示词。
按 v1.5.5 规范建立每段参考表，并在实际调用镜头绑定素材。
保持人物、道具、眼线、轴线与跨段声音连续。
剧本：[粘贴完整内容]
参考素材：[填写已提供内容]
```

## 四个审计工具

| 工具 | 本版用途 |
|---|---|
| `dialogue_timing.py` | 对白、标点、气口与反应时长估算 |
| `segment_timing_audit.py` | 模型时长档、分段容量与相关节拍审查 |
| `prompt_audit.py` | 旧版模块、参考编号、对白、时间码及执行规范检查 |
| `continuity_audit.py` | 基础人物、手位、道具和相邻段交接检查 |

使用历史源码或安装包内的对应示例运行；不要混用新版本命令参数：

```bash
python3 scripts/dialogue_timing.py --text '我不会再退了。' --mode restrained --format json
python3 scripts/segment_timing_audit.py examples/segments-seedance2.0.json --format json
python3 scripts/prompt_audit.py examples/quick-prompt.txt --contract quick --format json
python3 scripts/continuity_audit.py examples/continuity.json --format json
```

这些工具分别用于对白计时、分段配置、提示词结构和基础人物/道具交接检查。

## 与 1.6 / 2.0 有什么区别？

| 项目 | v1.5.5 历史社区版 | v1.6.0 稳定版 | v2.0.0-beta.1 预览版 |
|---|---|---|---|
| 安装标识 | `seedance-director-community` | `chuangmeng-director` | `chuangmeng-director` |
| 导演重点 | 对白编舞、反应、冲击、基础绑定与连续性 | 加强逐镜可见性、镜头相对眼线和动作相位 | 继承1.6，增加轻量状态驱动流程 |
| 节奏规则 | 约2–3秒有效视觉变化，允许有动机延长 | 默认2–4秒单镜，不超过4秒，可明确覆盖 | 继承1.6 |
| 参考策略 | 参考表 + 实际镜头绑定 | 默认集中于参考表，逐镜绑定为兼容策略 | 继承1.6 |
| 状态检查 | 基础人物/道具交接 | 基础交接与更明确的执行约束 | 新增逐镜事件回放和严格入口比对 |
| 使用建议 | 旧项目复现、沿用旧流程 | 新项目默认选择 | 试用与反馈状态账本 |

升级时同时检查安装标识、参考调用方式和审计参数。旧名与新名不同可能让两版同时存在；应在平台中明确选择本次要使用的版本，避免误触发。
